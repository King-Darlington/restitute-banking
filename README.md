# Restitute Banking

A TanStack Start + React + Tailwind project for refund recovery and banking.

## Development

Install Node.js and npm.

```sh
cd "d:\Freelancing\Restitute banking\Restitute Banking"
npm install
npm run dev
```

Create a `.env` file with your Supabase credentials:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_URL=
SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

Then open the dev server URL shown by Vite.
